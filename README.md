 ## Task Manager
A simple and efficient Task Manager application that helps users organize and track their daily tasks. Users can create, update, delete, and manage tasks with an easy-to-use interface.
Tech Stack: Java, Spring Boot, React.js, REST API, Axios, Docker, H2 Database, GitHub, Render
